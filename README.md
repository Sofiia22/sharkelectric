# Shark Electric landing page

A responsive, dependency-free single-page business card website based on the supplied Shark Electric artwork.

## Preview locally

Open `index.html` directly, or serve this folder with any static HTTP server.

## Responsive layout

- Desktop (`>= 1024px`): 3 columns × 2 rows
- Tablet (`768px–1023px`): 2 columns × 3 rows
- Mobile (`< 768px`): 1 column

## Estimate form

Estimate requests are sent to `sharkelectricoffice@gmail.com` through FormSubmit's AJAX endpoint. The mailbox owner must click the activation link in FormSubmit's first confirmation email before regular requests begin arriving.
